# FlowOps Glossary

| Term | Meaning |
|---|---|
| Branch | A separate line of work in a Git repository |
| Push | Uploading commits to a remote repository |
| Pull request | A request to review and merge one branch into another |
| Workflow | A GitHub Actions automation definition |
| Workflow run | One execution of a workflow |
| Webhook | An HTTP notification sent when an event occurs |
| Topic | A Pub/Sub resource that receives published messages |
| Subscription | A Pub/Sub consumer view of a topic |
| Dead-letter queue | Storage for repeatedly failing messages |
| Idempotency | Processing an event repeatedly without creating duplicate results |
| Apache Beam | A programming model for batch and streaming pipelines |
| Dataflow | Google Cloud’s managed Apache Beam runner |
| BigQuery | Google Cloud’s analytical data warehouse |
| Service account | A non-human identity used by a workload |
| HMAC | A keyed method used to verify message authenticity |
